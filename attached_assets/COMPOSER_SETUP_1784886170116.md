# KOKAO Composer — integration guide

One sheet that takes any post from draft to published (or scheduled) on every selected platform. This is the click-reduction patch: generate → publish is now 2 clicks, from ~7.

## Apply it (on top of the previous two patches)

```bash
git am composer.patch
```

That's it — **frontend-only**. No `db push`, no codegen, no new endpoints, no secrets. Restart the app.

## What changed

**Studio**: every generation is already auto-saved as a draft — there's now a primary **"Publish…"** button right next to Save. It opens the composer without leaving the page.

**Library**: every card gets one primary **"Publish / Schedule"** button. (The old per-platform buttons and dialogs are untouched underneath — once you're happy with the composer, deleting them is a safe cleanup pass I can do.)

**The composer sheet** itself:

- Editable caption + media preview (image or video)
- Platform checkboxes with live connection status — unconnected platforms are visibly disabled, never a surprise error
- A pre-publish checklist that runs **before** the click, using your shared `social-limits` helpers so warnings always match server behavior: Instagram-needs-an-image is a blocker; "will post as a thread of 4 tweets" / "overflow continues in 2 LinkedIn comments" are shown as info
- **Post now** publishes to all selected platforms sequentially with per-platform outcome reporting — a LinkedIn failure never hides a Facebook success
- **Schedule** creates one queue entry per platform at the chosen time (defaults to the next quarter-hour, one hour out)
- Caption edits are saved to the item before publishing, so every platform posts the same text
- Your last platform selection is remembered per browser
