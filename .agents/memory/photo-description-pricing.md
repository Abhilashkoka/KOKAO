---
name: Photo description pricing
description: Product photo analysis must have independent credit pricing.
---
AI product-photo descriptions use a dedicated credit pricing item, not the caption or image-generation price.

**Why:** The owner explicitly requested an “AI photo description” item in Credit Usage Pricing, created if absent.

**How to apply:** Preserve administrator-set prices when adding this capability to an existing rate card. Reusing a saved description is not a new billable operation.
